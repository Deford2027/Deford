# Анжела Богатырёва — лендинг

Вёрстка одностраничного сайта мастера перманентного макияжа и микроблейдинга по макету Figma
«Перманентный макияж / микроблейдинг, Севастополь».

## Структура

- `index.html` — разметка страницы
- `css/style.css` — стили (десктоп 1440 по макету + адаптив до 320px)
- `js/main.js` — мобильное меню, фильтр и стрелки портфолио
- `img/` — фотографии и логотипы, выгруженные из макета
- `icons/` — SVG-иконки из макета
- `fonts/` — шрифт Tilda Sans (Regular, Semibold)

Сборка не нужна: достаточно открыть `index.html` в браузере. Карта в контактах — виджет Яндекс.Карт, для неё нужен интернет.

## Что проверить перед запуском

- Ссылки на Telegram (`https://t.me/`) и юр. документы (`#`) — в макете их нет, нужно подставить реальные.
- Реквизиты УНП / ОГРНИП в подвале не заполнены в макете.
- Номер в шапке (+7 (495) 120-00-74) отличается от номера в контактах (+7 (916) 452-86-89) — так в макете.

## Лендинг автосалона (`auto/`)

Отдельная страница `auto/index.html` (стили `auto/css/style.css`, скрипт `auto/js/main.js`) повторяет структуру и композицию plutosauto.ru.
Код, иконки и тексты написаны заново, фото и логотипы партнёров — заглушки.

Блоки по порядку: первый экран, о компании, популярные модели, «берём на себя», квиз из четырёх шагов, кейсы (слайдер),
этапы работы, форма расчёта, «автомобиль мечты», услуги с формой, партнёры, частые вопросы, контакты, подвал.

Экран пропорционально масштабируется в сетках 1200 / 960 / 640 / 320, на телефонах меню открывается бургером.

- Тексты, логотип, адрес, телефоны и характеристики машин — примеры, их нужно заменить.
- Фото: замените блоки `.ph` на `<img>` или фон; видео первого экрана кладётся в `auto/media/` (тег `<video>` подготовлен).
- Формы и квиз проверяют поля, но никуда не отправляют данные — подключите отправку к CRM или почте в `auto/js/main.js` (функция `fakeSubmit`).
- Карта — заглушка со ссылкой; можно вставить виджет Яндекс.Карт, как в основном лендинге.
