# Планёрка студии

Доска задач на неделю, проекты и учёт времени для команды студии. Открывается в браузере по ссылке GitHub Pages, вход по общему паролю студии.

## Как устроено

- `index.html` — всё приложение (без сборки).
- `config.js` — адрес и публичный ключ проекта Supabase и служебная почта общего входа.
- `supabase-setup.sql` — таблица, права доступа и хранилище файлов. Запускается один раз в Supabase → SQL Editor.

Данные лежат в Supabase (бесплатный тариф). Читать и менять их может только тот, кто вошёл по общему паролю: это проверяет сам Supabase, а не страница, поэтому публичный ключ в `config.js` ничего не открывает.

## Сменить пароль

Supabase → Authentication → Users → пользователь `studio@example.com` → Reset password / Update user. После смены всем нужно войти заново.

## Важно про бесплатный Supabase

Проект на бесплатном тарифе засыпает, если к нему неделю никто не обращался. Пока команда пользуется планёркой каждый день, этого не случится; если всё-таки уснул, его включают кнопкой Restore в панели Supabase, данные сохраняются.
