# Перенос страниц Teyes Sibir на Tilda

Ты — перевозчик: берёшь готовую страницу из репозитория и ставишь её на teyes-sibir.ru
так, чтобы на сайте было ровно то, что в репозитории, с SEO, без битых ссылок,
и это доказано проверкой живой страницы. Текст и цены ты не сочиняешь.

## Где что лежит

- Репозиторий: `~/Documents/teyes-sibir-site` (правила — его `CLAUDE.md`).
- Загрузчик: `scripts/na_tildu.py`. Ходит в MCP Tilda по HTTP сам, код через модель
  не проходит. Ключ: `~/.config/tilda/mcp_token_artemiy` — не читать, не печатать.
- Источник страницы: `src/<slug>.html` (META в первой строке) → собирается
  `python3 scripts/sobrat.py` в `services/<путь>/index.html`. Исключение — камеры:
  `services/cameras/index.html` правится напрямую, src у неё нет.
- SEO берётся из комментария «SEO-поля страницы» в шапке `services/…/index.html`:
  Адрес, Title, Description, H1, Keywords, Цены. В src это поля META `url`, `title`,
  `description`, `h1`, `keywords`, `prices_note`.
- Реестр «адрес на сайте → страница/блок в Tilda»: `scripts/tilda_pages.json`.
  Фото, уже залитые на CDN Tilda: `scripts/tilda_images.json`. Ведёт скрипт сам.
- Статусы страниц: `docs/СТРАНИЦЫ.md`.

## Порядок

1. **Состояние.** `cd ~/Documents/teyes-sibir-site && git status --short && git log --oneline -3`.
   Незакоммиченные правки страниц — сначала понять, чьи они, и закоммитить.
2. **Правка, если нужна.** Цена, текст, ключевые слова — в `src/<slug>.html`, затем
   `python3 scripts/sobrat.py`. В diff должны поменяться только нужные страницы.
3. **Сухой прогон:** `python3 scripts/na_tildu.py services/<путь> --check`
   (несколько путей через пробел или `--all`). В Tilda ничего не пишет.
   «СТОП» — чинить в источнике, не обходить. «ВНИМАНИЕ» — запомнить для отчёта.
   Обязательно на каждой странице (иначе СТОП): title, description, H1 ровно один и совпадает
   с SEO-полем, Keywords, alt у каждой картинки. Решение Артёма 11.10.2026: «SEO-слова,
   альт-теги, тайтлы, H1 на всех этих страницах должны быть».
4. **Публикация — только после разрешения Артёма:** `python3 scripts/na_tildu.py services/<путь> --publish`.
   Скрипт сам: берёт свою страницу из реестра или создаёт новую, пишет код и сверяет
   его байт в байт, ставит title/description/keywords/canonical/короткое имя, публикует,
   ждёт на живой странице метку новой версии `data-tsb-ver` — она считается от кода
   и SEO-полей вместе (без неё — ПРОВАЛ: сайт отдаёт старое из кеша) и проверяет 200, title, description, keywords, canonical,
   нет noindex, один H1, FAQPage, все ссылки и картинки — 200.
   Итог должен быть «ОПУБЛИКОВАНО и проверено». Страница — 3–25 секунд.
   Без `--publish` — черновик: в Tilda записано, на сайте без изменений.
   Скрипт сам останавливается, если на сайте уже есть страница с этим адресом,
   которую завёл не он (живые старые страницы не перезаписывает), если у страницы
   сменился «Адрес», если страница из реестра исчезла или её правили руками
   (больше одного блока). Во всех трёх случаях решает Артём.
5. **Учёт:** строка страницы в `docs/СТРАНИЦЫ.md` — статус «**на сайте** с <дата>»,
   адрес на сайте. Коммит на русском (что перенесено), `git push`.
6. **Отчёт Артёму:** таблица «страница → ссылка на teyes-sibir.ru», что проверено
   (строку итога скрипта), все «ВНИМАНИЕ» отдельным пунктом. Ссылки — кликабельные.

**Любая запись в Tilda — черновик, публикация, фото на CDN, удаление — только после
прямого разрешения Артёма в этой задаче** («загружай на тильду», «ставь на сайт»).
Без разрешения: правка в репозитории → push → ссылка на github.io и `--check`.
Решение 12.10.2026, дословно: «перед тем как что-то на тильду грузить спрашивай,
пока сам ничего не грузи без разрешения». Запуск скрипта без флага `--check`
уже пишет в Tilda (черновик) — его тоже не делать без «да».

## Запрещено / разрешено

| ❌ Запрещено | ✅ Разрешено |
|---|---|
| Вставлять код страницы через инструменты MCP руками (update_record с простынёй HTML) | `scripts/na_tildu.py` — файл уходит в Tilda без пересказа |
| Править код прямо в Tilda | Править `src/` (или файл камер) → пересобрать → загрузить |
| Обходить «СТОП» правкой скрипта или ручной заменой на сайте | Чинить причину в источнике страницы |
| Менять «Адрес» у страницы, которая уже на сайте, молча | Сначала решение Артёма: скрипт создаст новую страницу, старая останется — нужен 301 или снятие |
| Ставить фото «для красоты» с чужих сайтов или стоков, чтобы был alt | Только реальные фото работ Teyes Sibir: страницы работ, посты «Наших работ»; нет фото — нет блока работ, так и сказать |
| Писать в alt то, чего нет в кадре («регистратор крупно», когда видна магнитола) | Alt описывает кадр и работу: «Honda CR-V после установки Teyes CC4 и регистратора» |
| Писать «цены свои», когда скрипт пишет «ориентир по рынку» | Отдельным пунктом: «на странице цены рынка, не ваш прайс — назовите свои» |
| Считать «noindex» по всему HTML Tilda | Смотреть только `<meta name="robots">`: в шапке Tilda есть служебные `<!--noindex-->` у форм |
| Создавать черновик в Tilda «заодно», без спроса | Сначала github.io-ссылка и вопрос «загружать на тильду?» |
| Говорить «готово» по ответу OK от Tilda | Готово — когда скрипт написал «ОПУБЛИКОВАНО и проверено» по живой странице |

## Правильно / неправильно

| ✅ Правильно | ❌ Неправильно |
|---|---|
| «Поменял цену подогрева в src, пересобрал, `--publish`: 1 из 1 без ошибок, 9 с» | «Обновил блок в Тильде, вроде встало» |
| «СТОП: ссылка `../nesushchestvuet/` — такой страницы нет. Сначала переносим её или убираем ссылку» | Заменить битую ссылку на главную, чтобы скрипт прошёл |
| «Keywords нет в SEO — добавляю в META и перезаливаю» | Публиковать без keywords, когда Артём их просил |

## Из настоящей истории (11.10.2026)

- «На тильде и ее положи по адресу https://teyes-sibir.ru/services/camera360»,
  затем «Делай на тильду дальге эти страницы» — семь страниц переносились вручную:
  код каждой страницы перепечатывался в вызов MCP. Через модель прошло 358 719 символов,
  половина — кириллица в виде `У…`. 3–5 минут на страницу.
  Ответ Артёма: «бля брат долго очень … Почему так долго?» → появился этот скрипт:
  запись 38 КБ — 1 с, страница целиком — 3–10 с.
- «И ставишь ли ты SEO в них? Нужны чтоыб ключевые слова и тайтл и дескриптор и h1 были» →
  keywords — поле `keywords` в META / строка «Keywords:»; скрипт предупреждает, если их нет.
- Ссылки `dashcam/` и `../closers/` вели на страницы, которых ещё не было на сайте, —
  пришлось снимать ссылки руками; первым прогоном скрипта (24 с) они вернулись. Теперь скрипт сам переводит относительные ссылки
  в адреса сайта по полю «Адрес» и останавливается, если страницы нет.
- В доводчиках был закомментированный шаблон с `ССЫЛКА_НА_РАБОТУ` и `src="ФОТО"` —
  скрипт вырезает комментарии с TODO и ловит заглушки.
- Камеры переехали на `/services/camera360`, а регистратор остался на вложенном
  `/services/cameras/dashcam`; исправлено на `/services/dashcam` в `src/dashcam.html`.
- На доводчиках, подогреве, электроприводе и мониторах опубликованы цены рынка,
  а не прайс компании — поэтому скрипт печатает «ВНИМАНИЕ: цены — ориентир».

- Ключевых слов не было ни на одной странице — Артём: «SEO-слова, альт-теги действительно
  тайтлс 1 у тебя на всех этих страницах должны быть». Keywords и alt стали обязательными.
  Фото работ нашлись только для регистраторов (страницы работ) и доводчиков (пост TANK 500);
  для подогрева, мониторов и электропривода реальных фото нет — блок работ там не ставили.
- Метка версии сначала считалась только от кода: когда поменялись одни keywords,
  проверка приняла старую страницу из кеша за новую и покраснела на keywords.
  Теперь в метку входят и SEO-поля.

## Самопроверка и её предел

Скрипт краснеет на главном: битая относительная ссылка, второй H1, H1 не совпал
с SEO, заглушки, TODO, код в Tilda не совпал с файлом, живая страница не отдаёт
нужные title/description/keywords/canonical, noindex, битые ссылки и картинки.
Проверено 11.10.2026 на подложенных плохих страницах: «СТОП» на несуществующей ссылке,
на двух H1 и на попытке записать в живую чужую страницу `/services/installation_teyes`.

Чего он не видит: правдивы ли цены и текст, как страница выглядит на телефоне,
не съела ли шапка Tilda верх страницы. Вопрос, на который отвечает человек:
**открой страницу с телефона — читается, кнопка звонка и Telegram работают?**

## Если скрипт перестал работать

Замер 11.10.2026: MCP Tilda `https://tilda.ru/api/mcp/`, заголовок
`MCP-Protocol-Version` (сервер вернул 2025-06-18), блок «HTML-код» = tplid 131.
Проверка связи: `python3 scripts/na_tildu.py --ping`.
- 401 — ключ протух: попросить у Артёма новый, путь к файлу не менять.
- Ошибка про заголовок или протокол — сервер сменил версию MCP: обновить `Mcp` в скрипте.
- Ошибка SSL в Python — запросы идут через `curl`, не переводить на urllib.
