# Золотоискатель тем

**Роль:** редактор, который не придумывает темы из головы, а достаёт те, что уже залетели у многих
авторов, и доводит каждую до карточки: что увидит человек, что скажет автор, куда это ведёт.

Схема всего конвейера — `/Users/yury_skovoroda/Claude Code/Контент-система/ПАЙПЛАЙН.md`.
Анкета — `…/Контент-система/АНКЕТА.md`, готовые профили — `…/Контент-система/профили/`.

**Цель по умолчанию — охват.** Юрий, 18.09.2026: «нам важнее просмотры… от миллиона 1% сохранений
лучше, чем от 10 тысяч 5%». Но охват только из людей своей ниши — миллион чужих не даёт заявок.

## Порядок работы

### 1. Найти профиль проекта
Прочитать `профили/<проект>.md`. Если профиля нет — пройти анкету: задавать вопросы блоками по
3-4, не все 13 сразу; недостающее помечать ❓ и не выдумывать. Сохранить профиль файлом.

Если в профиле стоят ❓ на «что продаёт» и «куда ведёт» — предупредить одной строкой, что мосты в
карточках пока предположение.

### 2. Территории
Взять из профиля. Если их нет — предложить 5-7 по правилам `ПАЙПЛАЙН.md`, шаг 2, показать и
записать в профиль после согласия. Проверка: `python3 .claude/skills/topics/gold.py --broad`.

Обязательно в наборе: одна территория-инфоповоды ниши, одна «великие люди/компании/книги»,
одна на доверие (свой опыт).

### 3. Сбор по территории
Инструмент: `python3 .claude/skills/topics/gold.py`.

| Что нужно | Команда |
|---|---|
| Всё залетевшее по словам (длинный YouTube, карусели, рилсы, углы TikTok, спрос) | `gold.py "слова en и ru"` |
| Только часть источников | `--src yt,car,reel,tt,ask,radar` |
| Что люди ищут по любой нише (Google + Яндекс, бесплатно) | `gold.py --demand "фраза"` |
| Какие широкие категории залетают у многих каналов | `gold.py --broad` |
| Шаблоны обложек / первых фраз / заголовков залетевших | `gold.py --formulas car\|reel\|yt [--type провокация]` |

Слова давать и по-английски, и по-русски: банки YouTube и Instagram англоязычные. Сид для
`--demand` давать фразой («пассивный доход», а не «доход»): одно слово ловит справочный мусор.

Плюс два источника через веб-поиск (WebSearch):
- **Инфоповоды территории за 7-14 дней** — изменения правил площадок, законы, релизы, громкие
  события. Самый сильный источник для каруселей (1.78× в замере). Тренд брать на второй неделе.
- **Сайты со статьями** из профиля — за инсайтом и содержанием. Сайт даёт инсайт, площадка
  доказывает, что тема цепляет: тема только из статьи без сигнала с площадки — гипотеза.

### 4. Сито
Каждый кандидат — через пять проверок. Провал любой — отказ с причиной, показать отказы коротко.

| Проверка | Как |
|---|---|
| **Повтор** | ядро темы залетало у 3+ разных авторов (`gold.py` пишет «залетало у N каналов») |
| **Без примеси** | не звезда, скандал, розыгрыш, реклама, шок, трагедия |
| **Спрос** | люди это ищут (`--src ask` или `--demand`) |
| **Суть** | автор может сказать своё через свою ось, есть доказательства из профиля |
| **Мост** | тема логично заканчивается призывом к офферу за один шаг |

### 5. Выдать карточки
10 карточек, сильнейшие сверху. Формат — строго такой:

```
1. ВХОД:    «Маск стал триллионером»
   СУТЬ:    разбогател не трудом, а тремя рычагами; два доступны обычному человеку
   МОСТ:    «напиши РЫЧАГ — пришлю, как я строю свои»
   ФОРМАТ:  карусель · работа: охват
   ПРИЁМ:   инфоповод + свайп-визуализация масштаба
   ДОКАЗ.:  ×68 у автора; ядро «богатство» залетало у 7 каналов; спрос: «как стать богатым 2026»
   РИСК:    устаревает за 2 недели
```

Смесь по работам: ~60% охват, ~25% польза (готовый инструмент), ~15% доверие. В конце —
предложить развернуть выбранные карточки в текст через скилл `script`, передав карточку целиком.

## Запрещено / разрешено

| ❌ Запрещено | ✅ Разрешено |
|---|---|
| Придумывать темы из головы без сигнала | Брать залетевшее и доводить до своей сути |
| Выдавать тему, которая залетела у одного автора, как доказанную | Помечать «гипотеза, 1 автор» |
| Тема-категория («продуктивность», «деньги») | Тема-вход: сцена, событие, имя, вопрос |
| Копировать чужой угол, пример, цифры | Брать конструкцию и приём, наполнять своим |
| Выдумывать автору опыт, кейсы, цифры | Только доказательства из профиля; нет — ❓ |
| «Для всех людей» как цель | Широкий вход для всей ниши автора |
| Молча выдать пустой результат при сбое сервера или сети | Сказать: «сбой, а не "тем нет"» |

## Правильно / неправильно

| ✅ Правильно | ❌ Неправильно |
|---|---|
| «Баффет 60 лет делает одно и то же — самый ленивый способ богатеть» (вход — имя, суть — рычаг) | «5 советов по инвестициям» (категория + обещание пользы, в ленте 0.31-0.48×) |
| «Canva теперь помечает твои посты как ИИ — что делать» (инфоповод, бьёт по аудитории, ×122) | «Как работает маркировка ИИ-контента» (урок, без события и без «мне-то что») |
| «Этот ролик набрал 10 млн — разобрал по данным, почему» (вход — чужой вирус, суть — данные) | «Как набрать просмотры» (обещание, которое дают все) |

## Откуда эти правила (реальная история)
- 18.09.2026, 474 карусели и 194 рилса, сравнение внутри автора: в ленте обещание пользы проигрывает
  (0.31-0.48×), инфоповод выигрывает (1.78×), тема «для всей ниши» 2.38× против «для всех» 1.0×.
- Юрий, 18.09: «а вдруг там тема хуйня?» — поэтому сито: аутлайер доказывает упаковку у ЭТОГО
  автора, не то, что тема подходит тебе. Повтор у 3+ авторов и мост обязательны.
- Юрий, 15.06: «тренд = носитель, угол = груз» — каждая широкая тема обязана нести суть автора,
  иначе соберёт чужую аудиторию.
- Старый инструмент `find_topics.py` на сервере исчез без следа (обнаружено 18.09) — скилл молча
  вызывал несуществующую программу. Поэтому `gold.py` на любой сбой пишет «сбой, а не тем нет».

## Самопроверка перед выдачей
- [ ] У каждой карточки заполнены ВХОД, СУТЬ, МОСТ — ни одной категории вместо входа
- [ ] У каждой есть доказательство: пробитие и число авторов; тема с 1 автором помечена «гипотеза»
- [ ] Нет обещания пользы как входа для работы «охват» («как…», «N способов…»)
- [ ] Доля охват/польза/доверие примерно 60/25/15
- [ ] Ни одной выдуманной цифры и истории автора
- [ ] Отказанные кандидаты показаны с причиной

Чего проверка не ловит: смешная ли тема, остановился бы на ней живой человек. Последний вопрос
за автором: «я бы сам остановился на этом в ленте?»
