# Метрика для админки на вайбкоде

Роль: делаю в админке сайта раздел, где владелец видит Метрику и Search Console без их
интерфейсов, – по проверенному образцу EV SIBIR (14.10.2026), с живыми данными и без
утечки токенов.

## Порядок

1. **Разведка.** Стек админки и где маршруты; есть ли авторизация (раздел только за ней);
   номер счётчика; домен для Search Console; своя база заявок (откуда «Заявки – все»);
   как выкладывается серверная часть. Нет авторизации – сначала она, не Метрика.
2. **Доступы** – по [references/access.md](references/access.md), только после «да»
   владельца: токен Яндекса только на чтение (через уже существующее OAuth-приложение,
   если есть), сервисный аккаунт в Search Console. Секреты – в файлы 600, не в чат и не в
   команды. Проверка: `scripts/check_access.py` – должен показать доступ к счётчику,
   визиты и уровень доступа в Search Console.
3. **Макет.** Если раздела нет или он другой – сначала макет (артефакт) с пометкой
   «цифры – пример», образец: https://claude.ai/artifact/QDB3snUcEiiZcUcTG8QWd1.
   Структура сразу с двумя вкладками: «Показатели» (неделя, месяц, квартал, год – без
   сравнения) по умолчанию и «Сравнение». Код – после «нормально» от владельца.
4. **Данные.** Модуль отчёта по [references/report.md](references/report.md): периоды,
   отставание, фильтр «только люди», блоки, кэш, повтор на 429. Проверка – живой запуск
   модуля с печатью итогов по каждому режиму, ошибок в `errors` нет.
5. **Экран.** Серверный HTML по макету, всё из API – через escape, режим – по белому
   списку. Проверка: 4 режима, пустой кэш, ширины 375 и 1280 без горизонтальной прокрутки.
6. **Проверка и выкладка.** План – через `verify-plan`, перед коммитом – `change-reviewer`;
   шаги по ≤3 файла кода с коммитом. На сервере: бэкап файлов, копия, перезапуск, живой
   запуск обновления там же, страница отвечает. Старый код раздела удалить отдельным шагом.
7. **Отчёт владельцу:** что живое и с какими цифрами, чего нет и почему (честно: мало
   данных, не созданы цели, недоступен API).

## Запрещено / разрешено

| ❌ Запрещено | ✅ Разрешено |
|---|---|
| Ставить на сервер чужой инструмент целиком (metrika-export: панель без пароля, формулы в Excel) | Брать идеи и запросы к API, писать раздел в своей админке под паролем |
| Печатать токен, вставлять его в команду или URL | Буфер обмена → файл 600 одной командой, буфер очистить |
| Брать токен с правами на запись | `scope=metrika:read webmaster:hostinfo` |
| Заявки по сайту считать целью Метрики | «Заявки – все» из своей базы; цель – только для конверсии по каналам |
| Сравнивать год к году «минус год» по датам | Минус 364 дня – те же дни недели |
| Брать сегодня и последние 2–3 дня Google | Метрика – по вчера (с проверкой отставания), Google – по сегодня −3 |
| Один сбой (ключ Google, 429) роняет всё обновление | Блоки в своих `try`, старый кэш не затирать |
| Рисовать блок «на будущее» с текстом-заглушкой | Нет данных – нет блока, причина в отчёте владельцу |
| Открывать раздел сравнением периодов | По умолчанию «Показатели» за период, сравнение – отдельной вкладкой |
| Смешивать Яндекс и Google в одну цифру поиска | Две линии и две колонки; фразы Яндекса – из Метрики, Google – из Search Console |

## Правильно / неправильно

| ✅ Правильно | ❌ Неправильно |
|---|---|
| «Вебмастер: ответ 0 – сеть не достучалась, токен ни при чём, блок не делаю» | «Вебмастер не работает, нужен новый токен» |
| «Сумма страниц 20, итог 27 – добавил строку „адрес скрыт Метрикой“» | Показать 20 и считать, что остальное потерялось |
| «Цели окна скидки сайт шлёт, а в Метрике их нет – не считаются, могу создать» | Молча показать нули по этим целям |
| «171 визит за месяц – это правда: Метрика только после согласия на cookie» | Подогнать цифры или спрятать маленький трафик |

## Из истории EV SIBIR (14.10.2026)

- Владелец: «тут глянь очень крутой обзор метрики и каналов, давай такой в ЛК поднимем…
  только все проверь на безопасность» → чужой код только прочитан агентом: брать идеи
  безопасно, ставить на сервер нельзя (панель без авторизации, DNS-rebinding, формулы в
  Excel от посетителей).
- «а сам сделать можешь это все?» → доступы подключены в Chrome владельца: сервисный
  аккаунт добавлен в Search Console, токен Яндекса получен через существующее приложение
  «EV Sibir SEO – Claude Code», перенесён через буфер в файл 600.
- На сервере Метрика ответила 429 «квота для IP» – IP общий с другими проектами →
  повторы 2/4/8 с и два потока вместо трёх.
- На маке python.org без корневых сертификатов: `SSL_CERT_FILE=$(python3 -c "import certifi;print(certifi.where())")`.
- Владелец о первой версии: «за какой срок это? почему это в сравнении?… хочу показатели за
  неделю, месяц, квартал, год, а сравнение отдельно; не вижу, что от Гугла, а что от
  Яндекса» → вкладки «Показатели | Сравнение», поиск раздельно, «Поиск в Яндексе» из фраз
  Метрики.
- Ревизор поймал: битый ключ Google ронял обновление вместе с Метрикой; недели от начала
  периода теряли свежие дни; заглушка «Вебмастер скоро» – всё исправлено до выкладки.

## Самопроверка

```bash
python3 .claude/skills/метрика-для-админки-на-вайбкоде/scripts/check_access.py --counter <N> --gsc-site sc-domain:<домен>
```
Ловит: нет файла или не 600, токен не видит счётчик, у аккаунта нет доступа к ресурсу,
недоступность API по сети. **Не ловит:** верны ли цифры на экране и понятен ли раздел
владельцу – это проверяет живой запуск модуля, сверка одной цифры с интерфейсом
Метрики и взгляд владельца.

Факты об API проверены 14.10.2026 на живых запросах (группировки ym:s:*, isRobot,
searchAnalytics). Если запрос вдруг отвечает 400 – перепроверить названия скриптом и
справочником, а не править наугад.

нет данных, значит так и сказать.
