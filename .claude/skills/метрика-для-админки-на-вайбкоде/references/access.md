# Доступы: токен Яндекса и Search Console без утечек

Читать на шаге 2. Всё делается в Chrome владельца (claude-in-chrome) только после его
«да» на подключение: создаются учётные данные и выдаются права.

## Яндекс (Метрика и Вебмастер)

1. Открыть https://oauth.yandex.ru/ – список «Ваши приложения». Если уже есть приложение
   с правами «Яндекс.Метрика» и «Яндекс.Вебмастер» – взять его ClientID (он не секрет),
   новое не плодить. Иначе «Создать» → «Для доступа к API или отладки», права:
   Метрика – «Получение статистики, чтение параметров своих и доверенных счётчиков»,
   Вебмастер – «Добавление сайтов…, получение информации о статусе индексирования».
2. Запросить токен только на чтение:
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=<ClientID>&scope=metrika:read%20webmaster:hostinfo`
   Яндекс покажет токен на странице verification_code.
3. Перенести токен, не печатая его: тройной клик по токену → cmd+c в браузере →
   в терминале одной командой:
   ```bash
   mkdir -p ~/.config/yandex-metrika && umask 077 && T=$(pbpaste | tr -d '[:space:]') && \
   [[ "$T" =~ ^y0_[A-Za-z0-9_-]{30,}$ ]] && printf 'YANDEX_METRIKA_TOKEN=%s\n' "$T" > ~/.config/yandex-metrika/metrika.env && \
   chmod 600 ~/.config/yandex-metrika/metrika.env && echo "сохранён, длина ${#T}"; printf '' | pbcopy
   ```
   Буфер очищается сразу. Вкладку с токеном закрыть или увести на другую страницу.
4. На сервер – `scp` этого файла и `chmod 600` там. В git – никогда (строка в .gitignore).

## Google Search Console

1. Сервисный аккаунт с ключом JSON. У Артёма уже есть:
   `teyes-seo-admin@teyes-seo-admin.iam.gserviceaccount.com`, ключ `~/.config/gsc/teyes-sa.json`.
2. Search Console → ресурс сайта → Настройки → Пользователи и разрешения → «Добавить
   пользователя» → почта аккаунта → «Полный доступ» (нужен, чтобы скрипт выкладки сам
   отправлял sitemap; для одного чтения хватит «Ограниченного»).
   Прямая ссылка: `https://search.google.com/search-console/users?resource_id=sc-domain%3A<домен>`
3. Ключ на сервер – `scp` под именем из кода (`gsc-sa.json`), `chmod 600`, строка в .gitignore.

## Проверка

```bash
python3 .claude/skills/метрика-для-админки-на-вайбкоде/scripts/check_access.py \
  --counter <номер счётчика> --gsc-site sc-domain:<домен>
```
Ждём: права 0o600, «ответ 200, сайт <домен>», визиты числом, «доступ siteFullUser».
«Вебмастер: ответ 0» – сеть не достучалась (так было 14.10.2026 и с мака, и с VPS),
к токену отношения не имеет: блок Вебмастера не делать, пока не ответит.
