# Адаптивная вёрстка: рабочий стандарт

## Когда применять

Всегда, когда задача касается HTML или CSS:

- сгенерировать страницу, лендинг, статью, письмо, компонент;
- отрефакторить или починить существующую вёрстку;
- «сделать адаптивным», «поправить на мобиле», «почему съезжает»;
- встроить фрагмент в чужую страницу или CMS.

Не применять только к задачам, где визуальный слой не затрагивается вообще.

---

## Инварианты

Нарушать нельзя ни при каких условиях. Если требование задачи противоречит инварианту — сначала скажи об этом, потом предлагай решение.

1. Один источник стилей. Один `<style>` или один файл CSS. Не два блока, не «допишу ещё один в конец».
2. Ноль мёртвых правил. Каждый селектор в CSS встречается в разметке, каждый класс в разметке объявлен в CSS.
3. Ноль `style="…"` в разметке. Разовый отступ — это утилитарный класс.
4. Ноль `!important`. Если он понадобился — значит структура специфичности сломана, чини её.
5. Mobile-first. Только `@media (min-width: …)`. Базовые стили — мобильные.
6. Ни одного размера мимо шкалы. Все кегли, отступы и радиусы — из токенов.
7. Минимальный кегль 12px. Основной текст 16px и больше.
8. Каждый ребёнок грида и флекса получает `min-width: 0`.
9. Кликабельная зона не меньше 44×44px.
10. `:focus-visible` задан. Страница проходима с клавиатуры.

## Шаг 0. Определи контекст

До первой строки кода ответь себе на три вопроса. Если ответ не следует из задачи — выбери значение по умолчанию и укажи его в ответе одной строкой.

**Куда встраивается.**
- *Отдельная страница* — есть `<head>`, можно подключать шрифты, задавать `:root`, работать с `<body>`.
- *Фрагмент внутри чужой страницы* (CMS, конструктор, виджет) — нет `<head>`, нельзя трогать глобальные стили, все правила вложены в корневой класс с префиксом, ширину окна знать нельзя. Это более жёсткий режим — если не уверен, работай в нём.

**Тема.** Тёмная, светлая или обе. По умолчанию — обе, через `prefers-color-scheme`.

**Стек.** Чистый HTML/CSS, фреймворк, утилитарный CSS. По умолчанию — чистый CSS с переменными, без зависимостей.

## Шаг 1. Токены

Скопируй блок, поменяй цвета под задачу. Префикс `xx` замени на префикс проекта.

```css
.xx{
  /* ── Цвет: тёмная тема по умолчанию ─────────────────── */
  --xx-bg:        #05070b;
  --xx-surface:   #0d111b;
  --xx-surface-2: #131926;
  --xx-line:      rgba(255,255,255,.12);
  --xx-line-soft: rgba(255,255,255,.07);
  --xx-text:      #f2f5fa;
  --xx-muted:     #a8b2c3;   /* вторичный текст */
  --xx-dim:       #8b95a8;   /* подписи — нижняя граница контраста */
  --xx-accent:    #4aa8ff;
  --xx-accent-2:  #43e3b5;
  --xx-on-accent: #04121a;

  /* ── Типографика ────────────────────────────────────
     Шкала 320px → 1240px, база 16 → 17px, шаг 1.2 → 1.25 */
  --xx-fs-xs:  clamp(0.8125rem, 0.79rem + 0.11vw, 0.875rem);   /* 13 → 14 */
  --xx-fs-s:   clamp(0.875rem,  0.85rem + 0.13vw, 0.9375rem);  /* 14 → 15 */
  --xx-fs-m:   clamp(1rem,      0.97rem + 0.13vw, 1.0625rem);  /* 16 → 17 */
  --xx-fs-l:   clamp(1.125rem,  1.08rem + 0.24vw, 1.3125rem);  /* 18 → 21 */
  --xx-fs-xl:  clamp(1.375rem,  1.29rem + 0.43vw, 1.6875rem);  /* 22 → 27 */
  --xx-fs-2xl: clamp(1.625rem,  1.47rem + 0.76vw, 2.0625rem);  /* 26 → 33 */
  --xx-fs-3xl: clamp(2rem,      1.74rem + 1.30vw, 2.75rem);    /* 32 → 44 */
  --xx-fs-4xl: clamp(2.5rem,    2.02rem + 2.39vw, 4rem);       /* 40 → 64 — только для рекламных обложек */

  --xx-font: system-ui, -apple-system, BlinkMacSystemFont,
             "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
  --xx-font-mono: ui-monospace, SFMono-Regular, Menlo, Consolas, monospace;

  --xx-lh-tight: 1.12;   /* крупные заголовки */
  --xx-lh-head:  1.2;    /* обычные заголовки */
  --xx-lh-body:  1.7;    /* абзацы */

  /* ── Отступы: одна шкала на весь проект ─────────────── */
  --xx-sp-3xs: clamp(0.25rem, 0.24rem + 0.05vw, 0.3125rem);  /*  4 →  5 */
  --xx-sp-2xs: clamp(0.5rem,  0.48rem + 0.11vw, 0.5625rem);  /*  8 →  9 */
  --xx-sp-xs:  clamp(0.75rem, 0.72rem + 0.16vw, 0.875rem);   /* 12 → 14 */
  --xx-sp-s:   clamp(1rem,    0.96rem + 0.22vw, 1.125rem);   /* 16 → 18 */
  --xx-sp-m:   clamp(1.5rem,  1.43rem + 0.33vw, 1.75rem);    /* 24 → 28 */
  --xx-sp-l:   clamp(2rem,    1.87rem + 0.65vw, 2.5rem);     /* 32 → 40 */
  --xx-sp-xl:  clamp(2.75rem, 2.49rem + 1.30vw, 4rem);       /* 44 → 64 */
  --xx-sp-2xl: clamp(3.5rem,  3.02rem + 2.39vw, 5.5rem);     /* 56 → 88 */

  /* ── Геометрия ──────────────────────────────────────── */
  --xx-r-s: 12px;
  --xx-r-m: 16px;
  --xx-r-l: 22px;
  --xx-gutter:  clamp(1rem, 0.8rem + 1vw, 1.5rem);  /* 16 → 24 */
  --xx-max:     1180px;
  --xx-measure: 68ch;
  --xx-tap:     44px;
  --xx-anchor:  0px;    /* высота липкой шапки; поднять, если она есть */

  --xx-ease: cubic-bezier(.22,1,.36,1);
}

/* Светлая тема — если проект её поддерживает */
@media (prefers-color-scheme: light){
  .xx{
    --xx-bg:#ffffff; --xx-surface:#f6f8fb; --xx-surface-2:#eef2f7;
    --xx-line:rgba(6,12,24,.14); --xx-line-soft:rgba(6,12,24,.08);
    --xx-text:#0b1220; --xx-muted:#465063; --xx-dim:#5a6478;
  }
}
```

**Правило проверки:** если в CSS появилось число, которого нет в токенах, — либо оно ошибочно, либо шкалу надо расширить осознанно, а не на глаз.

## Шаг 2. База

```css
.xx{
  box-sizing:border-box;
  color:var(--xx-text);
  background:var(--xx-bg);
  font-family:var(--xx-font);
  font-size:var(--xx-fs-m);
  line-height:var(--xx-lh-body);
  -webkit-text-size-adjust:100%;   /* Safari не раздувает текст при повороте */
  -webkit-font-smoothing:antialiased;
}
.xx *,.xx *::before,.xx *::after{ box-sizing:inherit; }

.xx img,.xx video,.xx svg,.xx canvas{ display:block; max-width:100%; height:auto; }
.xx p{ margin:0 0 var(--xx-sp-s); }
.xx h1,.xx h2,.xx h3,.xx h4{ margin:0; font-weight:800; letter-spacing:-.02em; }

.xx :where(a,button,summary,[tabindex]):focus-visible{
  outline:2px solid var(--xx-accent);
  outline-offset:3px;
  border-radius:4px;
}

@media (prefers-reduced-motion:reduce){
  .xx *,.xx *::before,.xx *::after{
    transition:none !important; animation:none !important; scroll-behavior:auto !important;
  }
}
```

`!important` здесь — единственное допустимое исключение: он гасит анимации по требованию системной настройки доступности.

**Контейнер:**

```css
.xx__page{
  width:100%;
  max-width:var(--xx-max);
  margin-inline:auto;
  padding-inline:var(--xx-gutter);
}
```

Не `width: 90%`, не `margin: 0 5%`. Максимальная ширина плюс внутренние поля — иначе на широком экране строки растянутся, а на узком контент прилипнет к краям.

## Шаг 3. Типографика

| Токен | Размер | Назначение |
|---|---|---|
| `--xx-fs-4xl` | 40 → 64 | обложка, рекламный экран — по запросу |
| `--xx-fs-3xl` | 32 → 44 | H1, один на страницу |
| `--xx-fs-2xl` | 26 → 33 | H2 |
| `--xx-fs-xl` | 22 → 27 | H3, цена, крупная цифра |
| `--xx-fs-l` | 18 → 21 | лид, заголовок карточки |
| `--xx-fs-m` | 16 → 17 | основной текст |
| `--xx-fs-s` | 14 → 15 | подписи, кнопки, интерфейсный текст |
| `--xx-fs-xs` | 13 → 14 | подписи под медиа, метки, крошки |
| `0.75rem` | 12 | только капслок с `letter-spacing` |

**Правила:**

1. **H2 не больше чем вдвое крупнее основного текста.** Соотношение 3:1 и выше — заголовок орёт, страница читается как набор баннеров.
2. **`max-width` на всех абзацах:** `68ch` для кириллицы, до `75ch` для латиницы.
3. **`line-height`:** 1.7 текст, 1.2 заголовки, 1.12 самые крупные. Промежуточных значений не изобретать.
4. **`text-wrap: balance`** на заголовках, `text-wrap: pretty` на абзацах — убирает висячие строки.
5. **Никогда `overflow-wrap: anywhere` на обычном тексте.** Он рвёт слова посреди слога. Для длинных URL и адресов — точечно `word-break: break-word` на конкретном элементе.
6. Один `<h1>` на документ, уровни не перескакивают.

```css
.xx h1{ font-size:var(--xx-fs-3xl); line-height:var(--xx-lh-tight); letter-spacing:-.03em; text-wrap:balance; }
.xx h2{ font-size:var(--xx-fs-2xl); line-height:var(--xx-lh-head);  margin-block:0 var(--xx-sp-s); text-wrap:balance; }
.xx h3{ font-size:var(--xx-fs-xl);  line-height:var(--xx-lh-head);  margin-block:0 var(--xx-sp-2xs); text-wrap:balance; }
.xx-body{ max-width:var(--xx-measure); text-wrap:pretty; }
.xx-lead{ max-width:var(--xx-measure); font-size:var(--xx-fs-l); line-height:1.55; }
```

**Шрифты.** Указывать в `font-family` только то, что реально доступно. Ссылка на неподключённый шрифт означает, что вся страница уедет в системный фолбэк и замысел типографики пропадёт. Подключаешь свой — либо `@font-face` с реальным файлом и `font-display: swap`, либо системный стек.

## Шаг 4. Сетка

### Три брейкпоинта

```css
/* база: 320–599, мобильный */

@media (min-width:600px){ /* вторая колонка, кнопки в ряд */ }
@media (min-width:900px){ /* планшет-ландшафт: сплиты разворачиваются */ }
@media (min-width:1100px){ /* боковые колонки, широкие раскладки */ }
```

Одно значение — один `@media` на весь файл. Разбрасывать правила одного брейкпоинта по трём местам нельзя.

### Сетки без медиазапросов

Для наборов однотипных карточек количество колонок считает сама сетка — от ширины **контейнера**, а не окна:

```css
.xx-grid{
  display:grid;
  gap:var(--xx-sp-xs);
  grid-template-columns:repeat(auto-fit,minmax(min(240px,100%),1fr));
}
.xx-grid > *{ min-width:0; }
```

`min(240px,100%)` обязателен: без него на экране уже 240px появляется горизонтальный скролл.

Это применимо к плиткам, галереям, спискам характеристик, карточкам товаров, блокам «связанное». Медиазапросы для них не нужны вообще, и такая сетка корректно работает даже внутри узкой чужой колонки.

### Container queries — для переиспользуемых компонентов

Если компонент может оказаться в контейнере любой ширины, привязывайся к контейнеру, а не к окну:

```css
.xx-card-host{ container-type:inline-size; }

@container (min-width:420px){
  .xx-card{ grid-template-columns:120px minmax(0,1fr); }
}
```

Медиазапрос по окну в такой ситуации врёт: окно 1400px ничего не говорит о том, что колонка 320px.

### Разделители в сетке

Не `nth-child`. Просвет плюс фон контейнера:

```css
.xx-table{
  display:grid;
  grid-template-columns:repeat(auto-fit,minmax(min(200px,100%),1fr));
  gap:1px;
  overflow:hidden;
  border:1px solid var(--xx-line);
  border-radius:var(--xx-r-m);
  background:var(--xx-line);          /* линии — это гэп */
}
.xx-table > *{ min-width:0; background:var(--xx-surface); }
```

Работает при любом количестве ячеек и любом числе колонок. `nth-child(odd)` развалится, как только количество изменится.

### Sticky

```css
@media (min-width:1100px){
  .xx-layout{ grid-template-columns:minmax(0,1fr) 300px; gap:var(--xx-sp-xl); }
  .xx-rail__inner{ position:sticky; top:var(--xx-anchor); }
}
```

Чтобы `sticky` работал, **ни один предок не должен иметь `overflow` кроме `visible`**. Это причина №1 у «липкий блок не липнет». Если нужно обрезать содержимое — используй `overflow: clip` на конкретном элементе, а не `hidden` на общем предке.

## Шаг 5. Медиа

```html
<!-- Первое видимое изображение -->
<img src="hero.jpg" width="1600" height="900" fetchpriority="high" decoding="async"
     alt="Осмысленное описание содержимого">

<!-- Остальные -->
<img src="photo.jpg" width="1280" height="960" loading="lazy" decoding="async" alt="…">

<!-- Если доступны несколько размеров -->
<img src="photo-800.jpg"
     srcset="photo-400.jpg 400w, photo-800.jpg 800w, photo-1600.jpg 1600w"
     sizes="(min-width:900px) 360px, (min-width:600px) 45vw, 92vw"
     width="1280" height="960" loading="lazy" decoding="async" alt="…">
```

Правила:

1. Атрибуты `width`/`height` — всегда, в реальных пропорциях. Резервируют место, убирают скачок вёрстки.
2. Размер в CSS — через `aspect-ratio`, никогда через фиксированную `height`.
3. `object-fit: cover` — для плотных сеток одинаковых плиток; `contain` — когда обрезать нельзя (товар, скриншот, логотип). Выбор внутри одной страницы должен быть последовательным.
4. `fetchpriority="high"` — ровно на одном изображении, первом видимом. На нём же не должно быть `loading="lazy"`.
5. `alt` — описание содержимого, а не повтор заголовка. Декоративная картинка — `alt=""`.
6. Не выдумывай URL-ы размеров, которых нет. Нет ресайзера — нет `srcset`.

**Текст поверх изображения.** Поверх управляемой графики — можно. Поверх фотографии, которую ты не контролируешь, — нет: яркость непредсказуема, и градиент, подобранный под один кадр, провалится на другом. Правильно — сплит: фото и текст отдельными блоками.

```css
.xx-hero{ display:grid; overflow:hidden; border-radius:var(--xx-r-l); }
.xx-hero__media{ order:-1; aspect-ratio:16/10; }
.xx-hero__media img{ width:100%; height:100%; object-fit:cover; }

@media (min-width:900px){
  .xx-hero{ grid-template-columns:minmax(0,1fr) minmax(0,1fr); }
  .xx-hero__media{ order:0; aspect-ratio:auto; min-height:100%; }
  .xx-hero__copy{ display:flex; flex-direction:column; justify-content:center; }
}
```

## Шаг 6. Мобильные ловушки

Эти вещи не видны на десктопе и ломаются только на реальном телефоне.

**`100vh` не равен высоте экрана.** Адресная строка меняет высоту, `vh` её не учитывает — блок оказывается выше экрана. Используй динамические единицы:

```css
.xx-screen{ min-height:100svh; }   /* гарантированно видимая часть */
/* 100dvh — подстраивается на лету; 100lvh — максимальная */
```

**iOS зумит страницу при фокусе на поле, если его кегль меньше 16px.** Всегда:

```css
.xx input,.xx select,.xx textarea{ font-size:max(16px,var(--xx-fs-s)); }
```

**Вырезы и жесты.** Для фиксированных панелей:

```css
.xx-bar{
  padding-block-end:calc(var(--xx-sp-s) + env(safe-area-inset-bottom));
  padding-inline:calc(var(--xx-gutter) + env(safe-area-inset-left));
}
```

**Широкое содержимое скроллится внутри себя, а не тянет всю страницу:**

```css
.xx-scroll-x{
  overflow-x:auto;
  overscroll-behavior-inline:contain;
  -webkit-overflow-scrolling:touch;
}
.xx-scroll-x > table{ min-width:max-content; }
```

Это стандартное решение для таблиц, длинных строк кода, лент вкладок и оглавлений.

**Горизонтальный скролл всей страницы** — всегда следствие конкретного элемента, а не «особенность мобильных». Ищи: элемент шире `100%`, отрицательный margin без компенсации, `min-width` без `min(…,100%)`, забытый `min-width: 0` во флексе, длинное неразрывное слово. Лечится причина, а не `overflow-x: hidden` на body — он вдобавок убьёт `sticky`.

**Якоря под липкой шапкой:**

```css
.xx-sec{ scroll-margin-top:var(--xx-anchor); }
```

## Шаг 7. Интерактив и доступность

```css
.xx-actions{ display:flex; flex-direction:column; gap:var(--xx-sp-2xs); }
.xx-btn{
  display:inline-flex; align-items:center; justify-content:center;
  min-height:var(--xx-tap);
  max-width:100%;
  padding:var(--xx-sp-2xs) var(--xx-sp-s);
  border-radius:999px;
  font-size:var(--xx-fs-s); font-weight:800; line-height:1.2;
  text-decoration:none; text-align:center;
  transition:filter .2s var(--xx-ease), transform .2s var(--xx-ease);
}
.xx-btn:active{ transform:scale(.985); }

@media (min-width:600px){
  .xx-actions{ flex-direction:row; flex-wrap:wrap; }
}
```

Обязательное:

- Кликабельная зона ≥ 44×44px. Ссылка 13px без вертикального паддинга — промах пальцем.
- Контраст: основной текст ≥ 7:1, вторичный ≥ 4.5:1. Серый на тёмном для мелкого текста проверяй, не полагайся на глаз.
- Раскрывающиеся блоки — нативный `<details name="группа">`, без JS. Атрибут `name` даёт поведение аккордеона.
- Смысловые теги: `<nav>`, `<article>`, `<section>`, `<aside>`, `<figure>`/`<figcaption>`, `<dl>` для пар «свойство — значение».
- `<main>` — ровно один на странице. Во встраиваемом фрагменте его быть не должно.
- `lang` на корневом элементе.
- Состояние не передаётся одним цветом — дублируй иконкой или текстом.

## Антипаттерны

Наиболее частые ошибки автоматической генерации вёрстки. Проверяй себя по этому списку.

| Антипаттерн | Чем оборачивается |
|---|---|
| Несколько `<style>` с наслоением поколений правил | Работает только последний, остальные конфликтуют; правки дают непредсказуемый результат |
| Правила для классов, которых нет в разметке | Файл распухает вдвое-втрое, поддержка становится невозможной |
| `!important` для разрешения конфликтов | Признак сломанной специфичности; следующий конфликт потребует ещё одного |
| Desktop-first с `max-width` | Мобильная версия оказывается набором заплаток поверх десктопной |
| Три копии одного брейкпоинта в разных местах файла | Правила противоречат друг другу, побеждает случайный порядок |
| Магические числа (`padding: 17px`, `font-size: 19px`) | Ритм разваливается, страница выглядит собранной из кусков |
| Кегли 9–11px | Нечитаемо, особенно на тёмном фоне |
| Текст поверх непредсказуемой фотографии | Нечитаемо на части устройств |
| `height: 280px` у изображений | Ломается при смене ширины колонки |
| `100vh` на мобиле | Блок выше экрана, контент под адресной строкой |
| `overflow: hidden` на общем предке | `position: sticky` перестаёт работать |
| `nth-child` для бордеров | Разваливается при другом количестве элементов |
| Отсутствие `min-width: 0` в гридах и флексах | Длинное слово или картинка распирает колонку |
| Инлайновые `style="…"` вперемешку с классами | Стили невозможно переопределить и найти |
| Шрифт в `font-family` без подключения | Вся типографика уезжает в системный фолбэк |
| Отсутствие `width`/`height` у картинок | Скачки вёрстки при загрузке, плохой CLS |
| Якоря без `scroll-margin-top` | Заголовок уезжает под липкую шапку |
| `overflow-wrap: anywhere` на тексте | Слова рвутся посреди слога |

## Чеклист перед выдачей

Прогони полностью. Любое «нет» — переделывай.

**Структура**
1. Один источник стилей?
2. Каждый класс в CSS есть в разметке и наоборот?
3. Ноль `style="…"` и ноль `!important` (кроме `prefers-reduced-motion`)?
4. Теги закрыты, `id` уникальны, один `<h1>`, уровни заголовков не перескакивают?
5. Во фрагменте нет `<main>`, `<html>`, `<head>`?

**Адаптив**
6. Все медиазапросы — `min-width`?
7. Базовые стили мобильные?
8. Один `@media` на одно значение брейкпоинта?
9. Наборы карточек — на `auto-fit` + `min(…,100%)`?
10. У детей гридов и флексов есть `min-width: 0`?
11. Нет `overflow` на предках `sticky`-элементов?
12. Нет фиксированных `height` у медиа — только `aspect-ratio`?
13. Нет `100vh` — только `svh`/`dvh`?

**Типографика**
14. Все размеры из шкалы?
15. Минимальный кегль ≥ 12px, основной текст ≥ 16px?
16. H2 не крупнее текста больше чем вдвое?
17. У абзацев есть `max-width` в `ch`?
18. Шрифты из стека реально доступны?

**Мобильные ловушки**
19. Поля ввода ≥ 16px?
20. Широкое содержимое скроллится внутри своего контейнера?
21. Фиксированные панели учитывают `safe-area-inset`?

**Доступность**
22. Кликабельные зоны ≥ 44px?
23. `:focus-visible` задан?
24. Контраст проверен?
25. `prefers-reduced-motion` обработан?
26. У целей якорей есть `scroll-margin-top`?

**Медиа**
27. У всех картинок есть `width`/`height` и осмысленный `alt`?
28. Первой — `fetchpriority="high"`, остальным — `loading="lazy"`?

**Проверка глазами**
29. Мысленно прогони макет на 375, 768, 1280 и 1920px. На каждой ширине: не выезжает ли что-то по горизонтали, читается ли текст, нет ли пустых колонок и осиротевших строк?
30. Прогони на «плохих» данных: заголовок вдвое длиннее, отсутствующая картинка, один элемент вместо шести, очень длинное слово без пробелов.

## Порядок работы

1. Определи контекст (шаг 0) и назови выбранный режим одной строкой.
2. Разбери контент: сущности, обязательные и опциональные поля, что делать при пустых значениях.
3. Собери семантическую разметку без стилей.
4. Вставь токены, поправь цвета.
5. Напиши базовые — мобильные — стили.
6. Добавь надстройки по трём брейкпоинтам.
7. Прогони чеклист.
8. Выдай результат одним файлом целиком, без разбивки на части и без обрамляющих пояснений.

**Ориентир по объёму:** длинная контентная страница на 20 секций укладывается примерно в 50–55 КБ при 60–70 классах. Вдвое больше — почти наверняка мёртвый CSS или дублирующиеся правила.
