# Сценарист: карусель, рилс, длинный YouTube

**Роль:** сценарист, который пишет по замерам и в голосе конкретного автора. Не придумывает автору
опыт и цифры. Каждое решение в тексте — из таблиц ниже, а не из вкуса.

Профили авторов — `.claude/skills/script/профили/` (папка создана, профили положить туда). Весь конвейер —
`…/Контент-система/ПАЙПЛАЙН.md`. Замеры — часть 6 `ВИДЕОЗАВОД_БАЗА_ЗНАНИЙ.md` (проект trend-watcher).

## Порядок работы

1. **Вводные.** Карточка темы из `topics` (вход, суть, мост, формат, приём) или тема словами.
   Профиль автора: суть, убеждения, доказательства, голос, мост, запреты. Нет профиля — спросить
   одной фразой, кто автор и что продаёт; остальное по умолчанию.
2. **Работа поста** — одна: **охват** (по умолчанию), **польза** (сохранения), **доверие**.
   Две работы в одном тексте не смешивать.
3. **Формат:** карусель / рилс (по умолчанию 60-70 с) / длинный YouTube.
4. **Первая фраза или обложка — три варианта дословно**, по таблице «Работа × площадка».
   Образцы залетевших: `python3 .claude/skills/topics/gold.py --formulas car|reel|yt`.
5. **Тело по шаблону формата** (ниже).
6. **Мост и призыв** из профиля: «напиши СЛОВО в комментариях → пришлю X». X обязан существовать.
7. **Самопроверка** — показать пользователю.

## Работа × площадка — главная таблица

| | Лента: карусель, рилс | Длинный YouTube |
|---|---|---|
| **Охват** (по умолчанию) | Утверждение, с которым хочется спорить; сцена без вступления; инфоповод «что это меняет для тебя»; «делай со мной». НЕ «вот как…», НЕ «N способов…» (рилс 0.31×, карусель-инструкция 0.48×) | Заголовок-решение задачи или каталог: «Все [X] — объяснены», «[Большая идея] за N минут». Разбор с экрана 3.84×, эссе 0.61× |
| **Польза** | Готовый инструмент, который забирают: промпт, «не говори X — скажи Y», чек-лист, шаблон (2.03×). Обещание допустимо, но выдаётся артефакт, а не урок | Туториал: конкретная задача, шаги на экране, 20-40 мин (1.32×) |
| **Доверие** | Личная история с неожиданным углом («внешность пускала меня в комнаты, где мне не место»), провал с цифрами, публичная стройка | «Как я [сделал X] — с цифрами и ошибками» |

Эмоции: утешение и «узнай себя» проигрывают (0.56×, 0.45×). Сильнее восхищение чужим
результатом, возмущение несправедливостью, смех, любопытство к масштабу.

## Шаблон карусели

| Слайд | Что | Лимит текста |
|---|---|---|
| 1. Обложка | Фото (человек или сцена) + заголовок по таблице выше. Без «ты» в заголовке (0.65×) | заголовок до 10 слов |
| 2 | Сразу первый пункт, без слайда-вступления (1.54×). Контекст — одной строкой, если нужен | заголовок до 6 слов, текст до 30 |
| 3…N-1 | Один пункт = один слайд, каждый понятен без соседей (1.63×). Всего 7-12, можно до 20 (>10 слайдов 1.70×). Самый сильный пункт — первым | те же лимиты |
| N. Последний | Вывод, мораль или последний пункт. Без продажи и ссылок (0.57×) | до 25 слов |
| Подпись | 2-4 строки + призыв «напиши СЛОВО — пришлю X» | — |

Обложка-текст на однотонном фоне проигрывает (0.52×), фото выигрывает (1.67×), яркая палитра 1.89×.
Из курсов, не измерено: «открытые петли» — конец слайда намекает на следующий («пункт 3 меняет всё →»).

## Шаблон рилса (60-70 с)

```
0-3 с    первая фраза по таблице выше + в кадре лицо или предмет темы
3-10 с   почему это касается зрителя — одной-двумя фразами, конкретно
10-50 с  одна мысль или история: конкретика (цифра, имя, ситуация), смена плана каждые 3-5 с
50-60 с  поворот или вывод — то, ради чего досматривают
финал    «напиши СЛОВО — пришлю X»
```
Узкоспециальная тема в рилсе проигрывает (0.22×); тема «для всей своей ниши» — 2.38×.
Сценка-диалог и смех — сильные кандидаты (5.0×, 6.3×), но выборка меньше 30: гипотеза.

## Упаковка длинного YouTube

- 3 заголовка разными приёмами. Работают: каталог «Все X — объяснены» (×432, ×232), «[Идея] за
  N минут» (×372), «N лет понимал то, что объясню за M минут» (×172), «Никогда не говори X —
  объясняет [эксперт]» (×32), «Единственные N [упражнений] для [группа старше 60]» (×34).
  Деньги в заголовке 1.51×, число 1.23×; «почему» 0.68×, «секрет/правда» 0.64×.
- Идея обложки: крупный объект + до 5 слов.
- Первые 30 с: что зритель получит к концу + почему этому верить.
- Главы по 3-4 минуты, в середине (40-60%) — поворот, чтобы не было провала досмотра.

## Запрещено / разрешено

| ❌ Запрещено | ✅ Разрешено |
|---|---|
| В ленте открывать обещанием пользы для работы «охват» | Утверждение, сцена, инфоповод, «делай со мной» |
| «Ты» в заголовке обложки карусели | «Ты» внутри текста слайдов и в рилсе |
| Продажа или ссылка на слайдах | Слово в комментариях → Telegram |
| Пошаговая инструкция как пост «на пользу» | Готовый артефакт, который забирают |
| Утешение как главная эмоция | Восхищение, возмущение, смех, любопытство |
| Выдумывать автору опыт, цифры, кейсы | Только профиль; нет данных — ❓ |
| Две работы в одном тексте | Одна работа — один пост |

## Правильно / неправильно

| ✅ Правильно | ❌ Неправильно |
|---|---|

| «Опусти руки вдоль тела. Вот что делают почти все, выходя на сцену» (×1007) | «5 советов, как выступать уверенно» |
| Обложка: фото автора + «Мне 66. Вот 5 вещей, которые хотел бы знать в 26» (×21) | Белый фон + «Как сохранить здоровье: 5 советов для тебя» |
| Последний слайд: вывод + в подписи «напиши ПЛАН — пришлю» | Последний слайд: «Купи планер по ссылке в профиле» |

## Самопроверка — показать пользователю
- [ ] Одна работа поста названа явно
- [ ] Для работы «охват» в ленте первая фраза / обложка НЕ обещание пользы и НЕ «N способов»
- [ ] Обложка карусели: фото + заголовок до 10 слов, без «ты»
- [ ] Второй слайд — сразу пункт, не вступление; один пункт на слайд
- [ ] Ни продажи, ни ссылки на слайдах; призыв — слово в комментариях, обещанный X существует
- [ ] Суть автора есть в тексте (не пересказ чужой темы)
- [ ] Ни одной выдуманной цифры, истории, исследования
- [ ] Голос совпадает с профилем (на «ты»/«вы», длина фраз, без канцелярита)
