# OpenRouter — модели, которых нет в API

**140 моделей**, снято 09.09.2026 из веб-каталога. `GET /api/v1/models` их не отдаёт —
там только 431 чат-модель. Цена за единицу работы (картинку, ролик, вызов), не за токены.

## ⚠️ Как их вызывать: НЕ через `/chat/completions`

Проверено 09.09.2026. Этих моделей нет в списке `/models`, и через обычный чат-эндпоинт
они не работают. У них **свои эндпоинты**, OpenAI-совместимые:

| Задача | Эндпоинт |
|---|---|
| Транскрибация | `POST /api/v1/audio/transcriptions` (multipart: `file` + `model`) |
| Синтез речи | `POST /api/v1/audio/speech` |
| Эмбеддинги | `POST /api/v1/embeddings` |
| Реранк | `POST /api/v1/rerank` |

Все четыре отвечают `400` на пустое тело — то есть существуют. Ошибка `404` означала бы,
что пути нет. **Не делать вывод «модели недоступны» только потому, что их нет в `/models`.**

Отдельно: **46 чат-моделей принимают аудио на вход** (поле `audio` в `pricing`) и могут
расшифровывать через обычный `/chat/completions` — например линейка `google/gemini-2.5-flash*`.
Это второй путь, когда нужен не голый текст, а разбор со смыслом.

⚠️ **Качество здесь не измерено.** Ниже — цена и тип задачи, то есть факты каталога.
Что из этого лучше под конкретную задачу — показывает только прогон на своём материале.
Порядок в таблицах — по цене, а не по «качеству».

## Как считать стоимость задачи

Цена за единицу × количество единиц. Примеры расчёта (**это арифметика, не рекомендация**):

- расшифровать 46 часов аудио через `whisper-large-v3-turbo`: ≈ 0.50 USD
- 100 картинок через `flux.2-pro` (0.03 USD): 3 USD
- 30 роликов через `seedance-1-5-pro` (0.023 USD): 0.69 USD
- 30 роликов через `veo-3.1` (0.40 USD): 12 USD

**Разброс цены внутри одной задачи — до 30 раз.** Какая из них подойдёт — решает
прогон на своём материале, а не позиция в таблице.
