## Возможности платформы, а не моделей

| Что | Как |
|---|---|
| **Батч** | суффикс `:batch` у модели — **вдвое дешевле**, но без гарантии времени |
| **Бесплатные** | суффикс `:free` — есть у Nex-N2.5-Pro, Inkling, Nemotron и десятков других |
| **Авто-выбор модели** | `openrouter/auto` — платформа сама решает, кому отдать |
| **Провайдеры** | `GET /api/v1/providers` → 105 штук. Можно фиксировать через `provider.order` |
| **Скидки** | в каталоге видны как «50% off»; в API их не видно — смотреть глазами |
| **Кэш ввода** | у части моделей есть `input_cache_read` дешевле обычного ввода |
| **Веб-поиск** | 17 моделей с `web_search_options`; тариф отдельный, в `usage` не виден |
| **Фактическая цена** | `GET /api/v1/generation?id=…` → `total_cost`. Баланс отстаёт, генерация — нет |
| **Обрезка ввода** | OpenRouter МОЛЧА режет длинный вход. Слать `"transforms": []` |
