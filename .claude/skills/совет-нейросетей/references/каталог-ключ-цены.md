# Ключ, прокси, каталог, цены

Рантайм-справка. В самом регламенте её нет намеренно — она вытесняла бы механики.

## Ключ

**В скилле ключа нет и не будет** — чтобы скилл можно было отдать, не отдав секрет.
Скрипт берёт сам, по порядку:

1. `~/.claude/secrets/openrouter.key` (права 600) — основное место
2. `$OPENROUTER_API_KEY`
3. нет ни там, ни там — попросить владельца

Ключ **не печатать** ни в ответах, ни в командах. Не хардкодить пути к `.env` чужих
сервисов: они переезжают и ломаются.

## Прокси

| Откуда | Прокси |
|---|---|
| С мака | **не нужен**, OpenRouter отвечает напрямую |
| С сервера в РФ | **нужен** — гео-блок, иначе 403 |

## Баланс

`GET https://openrouter.ai/api/v1/credits` → остаток = `total_credits − total_usage`.

## Цены: два разных представления, не перепутать

Здесь легко ошибиться на шесть порядков, поэтому явно:

| Где | Что означает число | Формула |
|---|---|---|
| Каталог API `pricing.prompt` | цена за **ОДИН токен** (`0.000002`) | `токены × цена` |
| Таблицы скилла и `СОВЕТ` в скрипте | цена за **МИЛЛИОН** токенов (`2.00`) | `токены × цена / 1e6` |

Обе формулы верны — для своего представления. Проверка на глаз: заход основным
составом стоит **десятые доли доллара**. Вышли центы или десятки — перепутано.

## Как искать свежие модели

1. `GET /api/v1/models` → фильтр **по вендору**, сортировка **по `created`**.
   Смотреть у каждого 2–3 самых свежих.
2. **Нельзя сортировать по цене** — наверх лезут старые дорогие модели, свежие
   тонут. Так однажды был проглядён целый флагман.
3. Полезно свериться глазами в браузере владельца
   (`openrouter.ai/models?order=newest&fmt=table`): там видны живые скидки,
   задержка и скорость, которых в API нет. **Осторожно: строки `(batch)` стоят
   рядом с обычными и стоят иначе** — так однажды была взята цена batch-версии.
4. API — программный источник, браузер — сверка. Не наоборот.

## Состав: замеры, а не константы

Цены, скорости и даты **протухают за недели**. Всё, что записано в скилле, —
замер на конкретный день, а не свойство мира. Перед серьёзным заходом
перепроверять, а не цитировать по памяти.
