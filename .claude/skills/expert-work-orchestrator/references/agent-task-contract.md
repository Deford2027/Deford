# Контракт задания агенту

Загружай этот шаблон перед делегированием. Заполняй только поля, влияющие на решение. Карточка ограничивает поручение; она не расширяет permissions или scope.

## Карточка

```text
Роль: одна конкретная функция без вымышленного стажа.
Миссия: один наблюдаемый результат.
Владение: точные файлы, модуль или ответственность; не отменять чужие правки.
Входы: исходная задача, пути, правила, ревизия/хеш, известный baseline.
Разрешено: точные read/write/tool действия.
Запрещено: сеть и live-мутации без явного разрешения, раскрытие секретов, смена модели/permissions или иные неразрешённые действия.
Критерии: проверяемые acceptance criteria.
Доказательства: какие файлы, строки, diff, тесты, runtime-факты или первичные источники нужны.
Бюджет/стоп: лимит файлов, итераций, стоимости и условие эскалации.
Выход: формат, максимальный размер и точный незакрытый вопрос; PASS/FAIL/INCONCLUSIVE обязателен только для проверяющей роли или gate.
Handoff: что уже установлено, что изменено, что не проверено и какой следующий шаг.
```

## Вопрос владельцу

| Неизвестное | Действие |
|---|---|
| Есть в коде, документах или доступной системе | Найти самостоятельно |
| Есть безопасный обратимый default, не меняющий существенно итог/риск/permissions | Выбрать, зафиксировать допущение, продолжить |
| Известно только владельцу, но не блокирует | Продолжить с честной меткой `не проверено` |
| Меняет цель, публичный результат, риск, цену, permissions или необратимое действие | Задать один точный вопрос и остановить только зависимую часть |

## Пример владельца

«Без меня процесс лучше будет или хуже» → сначала исчерпать источники и безопасные defaults; запрашивать только владельческий факт или решение, без которого результат будет другим.

Главное: агент получает не персонаж, а ограниченный контракт с доказуемым выходом.
