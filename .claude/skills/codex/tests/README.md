# Тесты скилла codex

Два набора, мешать их нельзя — они проверяют разное.

## Набор А: срабатывание описания

`срабатывание.md` — список фраз и ожиданий, `срабатывание.sh` — прогон.
Codex не трогает почти совсем, проверяет только, поднимается ли скилл на живую фразу.
**Прогонять после каждой правки описания.**

**Сначала залогинить CLI — без этого не поедет.** Проверено 2026-09-11 на 2.1.173:
`claude -p` отдаёт «Not logged in» и из песочницы, и без неё. Дело не в песочнице —
десктопное приложение авторизовано само по себе и с CLI своей авторизацией не делится.

Лечится один раз, в своём терминале:

```bash
claude login
```

После этого работают оба пути: и `срабатывание.sh`, и оптимизация описания
из `anthropic-skills:skill-creator` (`scripts/run_loop.py`) — она тоже гоняет `claude -p`.

Каждый вызов `claude -p` — отдельная свежая сессия, чистоту организовывать не надо.

**Осторожно с положительными фразами:** они доходят до реального вызова Codex и тратят
окно подписки. Для регулярного прогона держать отрицательные фразы и одну-две положительных.

## Набор Б: исполнение

`исполнение.md` — что проверяли, чем и с каким результатом. Требует живого MCP-сервера.
Восемнадцать тестов на 2026-09-11, все пройдены; три вскрыли неверные утверждения
в скилле, они исправлены.

**Два теста на отказ важнее остальных** — они проверяют не то, что всё работает,
а то, что поломка будет замечена:

- запись за пределы `cwd` под `workspace-write` — отказ обязан произойти и быть назван;
- разбор несуществующего файла — обязан сказать, что файла нет, а не выдумать содержимое.

## Чего не хватает

`claude plugin eval` в этой версии не существует — проверено, `claude plugin --help`
на 2.1.173 такой команды не отдаёт. Есть скилл `anthropic-skills:skill-creator` — он существует и внутри
есть готовый цикл оптимизации описания: 20 запросов, деление на обучающую и контрольную
части, по три прогона на запрос, до пяти итераций, выбор лучшего описания по контрольной
части. **Упирается в тот же нелогиненный `claude -p`.** Залогинить CLI — и он закрывает
набор А без самописного скрипта.
