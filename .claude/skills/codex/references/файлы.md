# Файлы: доказательства и частные случаи

Оперативные правила — в теле скилла. Здесь то, что стоит за ними: замеры, даты,
известные ограничения. Читать, когда правило дало сбой или нужно объяснить, почему оно такое.

## Откуда правило про чтение и запись

Проверено 2026-09-10 двумя прогонами. **Чтение:** Codex дали путь к файлу в чужой папке
с кодовым словом, которого он знать не мог, — прочитал и назвал верно. **Запись:**
при `workspace-write` попытка сохранить файл за пределы `cwd` не прошла, файл не появился.

Отсюда и берётся разделение: копировать в проект нужно только под правку.
Раньше в скилле стояло «Codex видит только то, что внутри `cwd`» — это было неверно
и исправлено по итогам теста.

## Картинка из переписки на диск не попадает

Проверено 2026-09-10. Приложенное в чат изображение приходит данными внутри разговора.
Искали `find` по временным папкам, кэшам, Downloads, Desktop и чтением буфера обмена
через AppleScript — файла нет нигде. Сохранить своими силами нельзя.

**Что делать:** попросить пользователя положить файл в `~/Downloads`.
Не подменять пересказом — генератор увидит пересказ, а не оригинал.

## Папка `~/Documents` недоступна

macOS не выдал Claude Code разрешение на неё. Вместо ошибки видна пустота: `ls` показывает
пустой каталог, хотя файлы там есть — это подтвердилось конфигом Codex, где перечислены
десятки его проектов внутри `~/Documents`.

**Чинится** в Системных настройках → Конфиденциальность и безопасность → Файлы и папки.
Пока не выдано — файл оттуда придётся перенести.

## Документы: чем подтверждено

Проверено 2026-09-10, оба направления.

**Создание.** Попросили акт `.docx`, смету `.xlsx` и презентацию `.pptx` с заданным
содержимым. Созданы все три, содержимое сверено независимой распаковкой архивов OOXML:
номер акта, ФИО, сумма, три строки таблицы с числами, три слайда с заголовками —
всё дословно.

**Чтение.** Новой беседой прочитали те же три файла плюс `.pdf`: шесть фактов из шести.

**Урок про проверку.** Первая распаковка `.xlsx` показала пустую таблицу — оказалось,
регулярное выражение не учло префикс пространства имён `x:`. Ошибка была в проверке,
а не в файле. Прежде чем обвинять Codex, перепроверить собственный инструмент.
