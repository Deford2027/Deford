# Segmind — медиа-задачи

## Свежесть чисел

Замерено **14.09.2026**. Каталог Segmind пополняется, а публичного списка без ключа нет —
поэтому числа здесь стареют молча. Называя их владельцу, добавлять «на 14.09.2026».
Точный счёт — только из кабинета Segmind.

Платформа под картинку, видео и звук: **512 моделей** и 292 готовых пайплайна.

## Твоя роль: дать кандидатов, а не выбрать за владельца

Он получает **список моделей под задачу** → прогоняет их сам на своём материале →
**сам решает**, увидев цену и результат.

От тебя нужны факты и кандидаты:

- тип задачи, цена за генерацию, что модель делает — это факты каталога;
- **качество ты не измерял.** «Лучше», «качественнее», «студийного уровня» без
  прогона — выдумка, на которой владелец построит неверный выбор;
- под задачу давать 2–4 кандидата с разницей в фактах и говорить прямо:
  сравнивать надо прогоном;
- цена за генерацию отличается в десятки раз — показывать разброс, а не «лучшее».

Полный список всех 512 моделей — `references/все-модели.md`, обновляется
скриптом `scripts/каталог.py`.

Полный каталог с ценами и списками моделей — `references/каталог.md`.

## Баланс — показывать всегда

**Первым делом каждого обращения** к этому скиллу выполнить и показать владельцу:

```
python3 .claude/skills/segmind/scripts/баланс.py
```

Эндпоинт неочевидный — `/v1/get-user-credits`. Догадки вида `v1/credits`, `v1/balance`,
`v1/user` отвечают 404 «Model information not found»: API принимает любой путь за имя
модели. Из-за этого легко решить, что баланса нет вовсе — **это неверно, он есть**.

Кредиты тратятся за генерацию. Если остаток меньше доллара — сказать прямо, что на
серьёзную задачу не хватит, и назвать ожидаемую стоимость по каталогу.

## Когда Segmind, а когда нет

| Задача | Куда |
|---|---|
| Сгенерировать/обработать картинку, видео, звук | **сюда** |
| Липсинк, субтитры, удаление фона, нарезка шортсов | **сюда**, у OpenRouter этого нет |
| Дообучить модель на своих фото | **сюда**, fine-tuning есть только здесь |
| Текст, рассуждения, агенты | `openrouter` — там 431 модель против 52 |
| Транскрибация, эмбеддинги, реранк | `openrouter`, там кратно дешевле |
| Разные мнения нескольких моделей | `совет-нейросетей` |

**LLM есть у обоих**, но у Segmind их 52 против 431. Гнать текст сюда незачем.

## Здесь есть утилиты, а не только генерация

Это фактическое отличие от OpenRouter: там таких моделей нет. Когда задача звучит
как «взять готовое и переделать» — смотреть сюда.

| Надо | Чем |
|---|---|
| Длинное видео → вертикальные шортсы | `OpusClip` |
| Субтитры прямо в видео | `VEED Subtitles`, 30 пресетов, один вызов |
| Убрать фон с видео без зелёнки | `VEED Video Background Removal` |
| Переозвучить с попаданием в губы | `VEED Lipsync v2` |
| Говорящий аватар из текста | `VEED Avatars`, `HeyGen Avatar V` |
| Оживить фото в говорящее видео | `Pruna P Video Avatar`, `VEED Fabric 1.0` |
| Разобрать картинку на прозрачные слои | `Seedream 5.0 Pro Layer Decomposition` |
| Вырезать объект в PNG | `Bria Extract Object` |
| Убрать объект, достроив фон | `Qwen Image Edit Plus Eraser` |
| Вставить товар в фон с подгонкой света | `Qwen Image Edit Plus Blend It` |
| Переверстать макет во все размеры баннеров | `Smart Banner Resizer` |
| Подменить лицо | `Segmind Faceswap v5`, `HyperSwap` |
| Из фото — 3D-модель | `Sam 3D Object`, `Sam 3D Body` |
| Примерить одежду | `Pruna P Image Try-On` |
| Вытащить речь из шума | `Elevenlabs Audio Isolation` |
| Клонировать голос | `Elevenlabs Voice Cloning` |

Полные списки — в справочнике. Перед выбором **свериться с каталогом**: модели
выходят каждую неделю.

## Pixelflows — 292 готовых пайплайна

Не модель, а собранная цепочка под задачу: примерка одежды, карточки товара,
рекламные креативы, фото-обработка. Если задача типовая — сначала искать готовый
пайплайн, а не собирать цепочку вручную.

⚠️ На pay-as-you-go доступно **только 5 Pixelflows**; Premium — с тарифа Business
(99 USD/мес). Это ограничение тарифа, а не техники.

## Деньги

**Платится за генерацию, не за токены.** Ориентир: картинка Nano Banana — 0.04. USD
Тарифы: pay-as-you-go от 10 USD · Pro 39 USD · Business 99 USD · Scale 599 USD в месяц.

**Видео идёт минутами.** Замеры: от 17 секунд до 8 минут на ролик. Таймаут щедрый,
владельца предупредить, что ждать долго.

**Чего нет у OpenRouter:** fine-tuning (A100 0.002 USD/сек, обучение Flux-Pro 3 USD–9) и
выделенные GPU по часам (A5000 0.68 USD/час … H100 9 USD/час) — когда вызовов много,
своё железо дешевле поштучной оплаты.

## API

Ключ: `~/.claude/secrets/segmind.key`, заголовок `x-api-key`.

⚠️ **Каталог через API не читается.** Все эндпоинты `api.segmind.com/v1/*` ждут
**POST с JSON-телом** — это API запуска. Без тела 400, без `Content-Type` 406.
Список моделей и цены — только в веб-каталоге.

## Запрещено / разрешено

| ❌ Запрещено | ✅ Разрешено |
|---|---|
| Называть модели по памяти | Свериться с каталогом |
| Запустить генерацию молча | Назвать цену и дождаться согласия |
| Собирать цепочку вручную, не глянув Pixelflows | Сначала искать готовый пайплайн |
| Обещать быстрый результат на видео | Честно сказать: минуты, иногда до восьми |
| Гнать сюда текстовые задачи | Отправить в «openrouter» |
| Молча дообучать модель | Fine-tuning — деньги и время, спросить |
| Оценивать качество, которого не мерил | Давать факты и предлагать прогон |
| Решать за владельца, что «лучше» | Дать кандидатов — тестирует и решает он |

**Главное:** давать кандидатов с фактами, решение оставлять владельцу — он
тестирует сам. Качество не выдумывать: не мерил — так и сказать. У Segmind есть
утилиты обработки готового материала, которых нет у OpenRouter. Сверяться с
каталогом, а не с памятью. Сначала искать готовый Pixelflow. Цену называть до
запуска, про минуты ожидания предупреждать.
