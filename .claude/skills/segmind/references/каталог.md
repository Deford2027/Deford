## Главное отличие от OpenRouter: утилиты, а не только генерация

Это то, ради чего Segmind вообще нужен. Ниже — не «сгенерируй красивое», а
конкретные операции над готовым материалом.

## Pixelflows — готовые пайплайны (292)

Не модель, а собранная цепочка. Разделы: Fashion (виртуальная примерка),
E-commerce (карточки товара), Photography, Advertising. Плюс шаблоны под конкретные
модели: GPT Image 1, Veo 3.1 Fast, Nano Banana Pro, Kling 2.5 Turbo, ElevenLabs TTS.

⚠️ На тарифе pay-as-you-go доступно только **5 Pixelflows**; Premium-шаблоны — с
тарифа Business.

### Чего нет у OpenRouter

**Fine-tuning:** A100 0.002 USD/сек, H100 0.0043 USD/сек, L40S 0.0015 USD/сек.
Обучение Flux-Pro: 3 USD (до 150 шагов), 6 USD (150–500), 9 USD (500+). Рекомендуют ~20
картинок. Нужен баланс от 10. USD

**Выделенные GPU** (платишь за железо, а не за вызов): H100 9 USD/час, A100 4.32 USD/час,
L40 2.66 USD/час, A6000/A40 1.73 USD/час, A5000 0.68 USD/час. Есть посекундная автоскейл-цена.

## API

Ключ: `~/.claude/secrets/segmind.key`, заголовок `x-api-key`.

⚠️ **Read-only каталога через API нет.** Все эндпоинты `api.segmind.com/v1/*` ждут
**POST с JSON-телом** — это API запуска моделей. Запрос без тела даёт 400, без
`Content-Type` — 406. Список моделей и цены смотреть только в вебе.
